# move_landingpage

[![No Maintenance Intended](http://unmaintained.tech/badge.svg)](http://unmaintained.tech/)

:globe_with_meridians: The landing page of Move, a service that shows you the nearest places selling what you need and delivers your order wherever you are.

## Usage
If you already have Node.js, Bower and Grunt installed on your machine, install the dependencies and serve the page:
```
npm install
bower install
grunt serve
```
